# CCMTV 考勤助手 (第一/二阶段全能版)

专为 **Loon** 与 **Shadowrocket** 设计的 CCMTV 移动端考勤自动化套件：
- **第一阶段（已实测验证通过）**：前端页面 DOM/JS 运行时注入锁定 + 提交请求体兜底重写双保险，无论身处何地打开 App 均可合规打卡，并顺风车捕获会话凭证。
- **第二阶段（全新升级）**：由 Cron 调度器在早/中/晚三大黄金窗口期由后台静默代打卡，内置“四道前置防火墙”（排班检测、防重打校验、时间窗口匹配、智能防风控随机延时）与凭据自愈告警机制。

## 🛡️ 第二阶段全自动“四道前置防火墙”机制

为彻底杜绝节假日误打卡、重复打卡或机器特征被风控识别，后台 Cron 严格按照以下流程执行：

1. **第一道防火墙：排班检测**  
   向 `/typeList` 查询当日排班。若遇轮休或无排班日，脚本瞬间安全退出，不等待、不发提交包。
2. **第二道防火墙：防重打校验**  
   向 `/getMySignTypeInfo` 查询候选班次状态。若检测到 `click == "0"` 或已有 `user_sign_in_time`（今日已打过卡），立即静默退出。
3. **第三道防火墙：时间窗口匹配**  
   仅在服务端下发的合法时间窗口内开放打卡。若未到开放时间或已截止，安全退出。
4. **第四道防火墙：智能防风控随机延时 (Anti-Risk Jitter)**  
   仅当**前置三道校验全部通过且具备打卡资格时**，才触发 0 ~ `RandomDelay`（默认 0~300 秒）的随机等待，随后再提交打卡，彻底抹平固化定时特征。

## 🔄 深度凭据自主自愈机制 (Zero-Touch Self-Healing)

1. **会话级自动续签**：针对夜间长时间黑屏休眠导致 PHP ci_session 会话超时注销的问题，脚本集成了基于永久 passport 令牌的自主重铸机制：
   - 当检测到 typeList 会话失效时，自动调用底层 AndroidGpApi/index 获取动态换票链接。
   - 请求换票接口自动从响应头直接提取全新 ci_session 并静默写入持久化存储，无需用户打开 App 即可无感自愈完成打卡。
2. **顺风车自愈双保险**：每次在手机上进入考勤主页或手动打卡时，拦截器依然会顺风车同步持久化最新 Cookie 与 Passport。

## ⚡ [Phase 2.5] 15分钟压哨生命线与晨间全盘对账看板

为确保 100% 绝对稳定交付与无心理负担体验，系统全面引入了双向防护：

1. **三大 15 分钟压哨生命线（07:45 / 14:15 / 22:45）**：
   - **已签到静默休眠**：若常规打卡已完成，生命线巡检 0.1 秒内安全退出，零弹窗、零打扰。
   - **未签到极速抢救**：若常规打卡未落盘，生命线跳过随机延时，立即发起无感自愈补签。
   - **死局高优告警**：若遭遇重度凭据注销或物理断网，立即拉响系统高优警报，留足 15 分钟呼叫人工打开 App 兜底。
2. **晨间全盘对账（07:20）**：
   - 早上完成早班打卡后，顺便核验昨日全天三大班次最终归档状态，出具对账单并提供人工复核指引，彻底消除隔夜焦虑。
